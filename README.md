# Kania Law Office — Concept Redesign

Vue 3 + Tailwind pitch demo for [kanialaw.com](https://www.kanialaw.com/). Not the live firm website.

## Run

```bash
npm install
npm run dev
```

Production: `npm run build` then `npm run preview`.

Optional: copy `.env.example` to `.env` and set `VITE_FORMSPREE_ID` so Ask a Lawyer delivers mail. Without it, the form stays an honest demo and points people to **918-743-2233**.

## Pitch talking points

1. Open **`/pitch`** first. Their live homepage vs this concept.
2. Same forest green, gold **K**, and *In Your Corner* — glove clipart gone, identity kept.
3. Signature **practice index** (large type, still swap) and **Oklahoma coverage map** are the two memorable moments.
4. Mobile: sticky consult bar. Their current layout is not built for a phone.
5. This is ~50%: home, practice hub, three practice pages, about, attorneys, contact. A paid build would add CMS, blog, full practice tree, Spanish site, and SEO URL migration.
